ArcGIS Pro 3.x Geoprocessing Suite

Custom ArcGIS Pro Toolbox (ArcGIS_Script_Tools.atbx)

A native ArcGIS Pro toolbox packaging five custom Python (arcpy) script tools with integrated ToolValidator routines for multi-field string auditing, spatial feature extraction, OpenStreetMap ingestion, automated reference basemap loading, and batch .pyt-to-.atbx migration.

ArcGIS_Script_Tools.atbx (v2.4.0)

Download Complete 5-Tool Geoprocessing Toolbox

Format: ArcGIS Pro Toolbox (.atbx)  |  Compatibility: ArcGIS Pro 3.x / Python 3 (arcpy)  |  Contains: 5 Custom Geoprocessing Script Tools with ToolValidator classes

Download .atbx Toolbox
Step 1 — Download Archive: Save ArcGIS_Script_Tools.atbx into your ArcGIS Pro project directory.
Step 2 — Add in Catalog Pane: In ArcGIS Pro, open the Catalog Pane → right-click Toolboxes → Add Toolbox.
Step 3 — Run or Chain in Models: Open any of the 5 script tools in the Geoprocessing pane or drag them into ModelBuilder.
Tool 01

StringSearcher

— Attribute String Searcher

Scans multiple text fields across a feature class or table using case-insensitive substring or regex matching (re, arcpy.da.SearchCursor), logging matched ObjectIDs, field names, and summary counts to the geoprocessing message pane.

View Parameters & Validation Logic (StringSearcher.tool)
Tool Parameters
  • • in_dataset (Feature Layer / Table View)
  • • search_fields (MultiValue String Field Filter)
  • • search_pattern (Substring or Regex Expression)
  • • use_regex & case_sensitive (Boolean Flags)
ToolValidator & Execution Logic

tool.script.validate.py dynamically inspects the input table schema via arcpy.Describe to populate only String-type fields. tool.script.execute.py iterates rows via arcpy.da.SearchCursor and outputs a structured QA/QC report.

Tool 02

SearchAndExtract

— Attribute Search & Spatial Extractor

Queries target text attributes across a feature layer, applies an attribute/spatial selection, and exports matching features to a new geodatabase feature class (arcpy.conversion.ExportFeatures) with an optional summary table and automatic active map layer insertion.

View Parameters & Validation Logic (SearchAndExtract.tool)
Tool Parameters
  • • in_features (Input Feature Layer)
  • • target_fields (Multi-Field Attribute Filter)
  • • query_string (Target Search Keyword)
  • • out_feature_class (Output Geodatabase Feature Class)
ToolValidator & Execution Logic

Constructs DBMS-agnostic SQL WHERE clauses using arcpy.AddFieldDelimiters, validates output table names in the target workspace, extracts matching geometries via arcpy.conversion.ExportFeatures, and adds the result to the active map.

Tool 03

OSMDownloader

— OpenStreetMap Spatial Downloader

Extracts OpenStreetMap vector features (highways, buildings, landuse, waterways, amenities) within a user-defined study area extent or template layer, converting raw OSM geometries into clean, projected geodatabase feature classes with standardised attribute schemas.

View Parameters & Validation Logic (OSMDOwnloader.tool)
Tool Parameters
  • • aoi_extent_or_layer (Study Area Polygon / Extent)
  • • osm_tags (Highways, Buildings, Landuse, Waterways, Amenities)
  • • out_spatial_ref (Target Coordinate System, e.g., EPSG:3005)
  • • out_gdb (Target File Geodatabase)
ToolValidator & Execution Logic

Transforms study area bounding coordinates to WGS84 for Overpass API querying, parses returned vector elements into point/line/polygon geometry objects, and reprojects output feature classes to the user's target CRS.

Tool 04

BasemapLoader

— Automated Basemap & Reference Layer Loader

Streamlines cartographic project setup in ArcGIS Pro (arcpy.mp.ArcGISProject) by batch-loading standard provincial/federal reference services (DataBC, GeoBC, CanVec) and basemap layers into active map frames and syncing spatial references.

View Parameters & Validation Logic (BasemapLoader.tool)
Tool Parameters
  • • target_map (Active Map or Map Frame Selection)
  • • basemap_preset (Topographic, Imagery, Light Gray, OSM)
  • • reference_layers (DataBC / GeoBC / CanVec Service URLs)
  • • spatial_reference (Target CRS Synchronisation)
ToolValidator & Execution Logic

Enumerates map frames in arcpy.mp.ArcGISProject("CURRENT"), attaches the selected basemap and provincial/federal reference layers, and enforces consistent projection properties across map series layouts.

Tool 05

BatchConvertPytToAtbx

— Batch .pyt to .atbx Toolbox Converter

Automates the migration of legacy Python Toolboxes (.pyt) across workspace directories into modern ArcGIS Pro .atbx toolboxes, preserving parameter definitions, tool.script.execute.py logic, tool.script.validate.py routines, and tool metadata.

View Parameters & Validation Logic (BatchConvertPytToAtbx.tool)
Tool Parameters
  • • in_workspace_or_pyts (Input Directory or MultiValue .pyt Files)
  • • out_folder (Output Directory for Generated .atbx Toolboxes)
  • • overwrite_existing (Boolean Flag)
ToolValidator & Execution Logic

Recursively discovers .pyt files in the selected workspace, validates write permissions on the output directory, and converts each Python toolbox into a self-contained ArcGIS Pro .atbx package.
