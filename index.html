ArcGIS Pro Script Tools

Custom ArcGIS Pro Toolbox (ArcGIS_Script_Tools.atbx)

Download my ArcGIS Pro toolbox (.atbx) containing five Python (arcpy) script tools for attribute string searching, spatial subset extraction, OpenStreetMap feature downloading, basemap loading, and batch .pyt-to-.atbx conversion.

ArcGIS_Script_Tools.atbx

Download Complete 5-Tool Geoprocessing Toolbox

Format: ArcGIS Pro Toolbox (.atbx)  |  Requires: ArcGIS Pro & Python 3 (arcpy)  |  Tools Included: 5

Download .atbx Toolbox
Step 1 — Download File: Save ArcGIS_Script_Tools.atbx into your ArcGIS Pro project folder.
Step 2 — Add in Catalog Pane: In ArcGIS Pro, open the Catalog Pane → right-click Toolboxes → Add Toolbox.
Step 3 — Run Tools: Open any of the 5 script tools in the Geoprocessing pane or connect them in ModelBuilder.
Tool 01

StringSearcher

— Attribute String Searcher (StringSearcher.tool)

Searches one or more text fields in a feature class or table for a target substring or regular expression pattern and reports matching ObjectIDs, field names, and match counts in the Geoprocessing messages pane.

Tool Structure & Script Files
Key Inputs
  • • Input dataset (Feature Layer / Table View)
  • • Target text fields to inspect
  • • Search string or regular expression pattern
Archived Scripts in .atbx

Includes StringSearcher.tool/tool.script.execute.py and StringSearcher.tool/tool.script.validate.py for dynamic field validation and cursor-based string inspection.

Tool 02

SearchAndExtract

— Attribute Search & Feature Extractor (SearchAndExtract.tool)

Queries selected text fields in an input feature layer for a target keyword or pattern and exports the matching records directly to a new geodatabase feature class.

Tool Structure & Script Files
Key Inputs & Outputs
  • • Input Feature Layer
  • • Target String Field(s) & Query Keyword
  • • Output Feature Class path
Archived Scripts in .atbx

Includes SearchAndExtract.tool/tool.script.execute.py, tool.script.validate.py, and tool.content metadata definitions.

Tool 03

OSMDownloader

— OpenStreetMap Spatial Downloader (OSMDOwnloader.tool)

Downloads OpenStreetMap vector features for a specified area of interest and converts the extracted geometries into geodatabase feature classes for use in ArcGIS Pro.

Tool Structure & Script Files
Key Inputs & Outputs
  • • Area of Interest extent or boundary layer
  • • Target OSM feature categories / tags
  • • Output Geodatabase workspace
Archived Scripts in .atbx

Includes OSMDOwnloader.tool/tool.script.execute.py, tool.script.validate.py, and tool.content configuration files.

Tool 04

BasemapLoader

— Basemap & Reference Layer Loader (BasemapLoader.tool)

Automates loading basemaps and reference layers into an active ArcGIS Pro map project (arcpy.mp.ArcGISProject) to speed up map setup and standardize project layouts.

Tool Structure & Script Files
Key Inputs
  • • Target ArcGIS Pro Map Frame
  • • Basemap / Reference Layer selection
Archived Scripts in .atbx

Includes BasemapLoader.tool/tool.script.execute.py, tool.content, and tool.content.rc resource definitions.

Tool 05

BatchConvertPytToAtbx

— Batch .pyt to .atbx Converter (BatchConvertPytToAtbx.tool)

Batch-converts Python toolboxes (.pyt) in a folder or workspace into modern ArcGIS Pro toolboxes (.atbx).

Tool Structure & Script Files
Key Inputs & Outputs
  • • Input folder or .pyt toolbox files
  • • Output folder for generated .atbx files
Archived Scripts in .atbx

Includes BatchConvertPytToAtbx.tool/tool.script.execute.py, tool.script.validate.py, and tool.content metadata.
